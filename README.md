# Swapnil & Mayuri — Wedding Invitation Website

A standalone, responsive wedding invitation website built with HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Safari or Firefox.
3. An internet connection is needed for Google Fonts and the sample background/placeholder photos. Your own local photos and music can be used offline.

## Personalise before sharing
Open `index.html` in any text editor (Notepad or VS Code) and update:
- `WHATSAPP_NUMBER` near the bottom: use digits only, with India country code 91 (example format: 919876543210).
- Haldi, wedding and reception times and venue details.
- Venue name, address and Google Maps link.
- Story text if you want to add your own story.

## Add your photos and music
Place these files in the `assets` folder, using exactly these names:
- `couple-portrait.jpg`
- `gallery-1.jpg`
- `gallery-2.jpg`
- `gallery-3.jpg`
- `gallery-4.jpg`
- `wedding-music.mp3`

Use photos and music that you own or have permission to publish. Music starts only after a visitor taps “Play music”, because modern browsers block autoplay with sound.

## Free public hosting with GitHub Pages
1. Sign in or create an account at https://github.com.
2. Create a new **public** repository, for example `swapnil-mayuri-wedding`.
3. Upload `index.html` and the complete `assets` folder to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two. GitHub will show your public website URL, usually:
   `https://YOUR-USERNAME.github.io/swapnil-mayuri-wedding/`
8. Open that URL on your phone and share it on WhatsApp.

## Important
- GitHub Pages hosting is free for public repositories, but the URL belongs to GitHub Pages. A custom domain is optional and usually costs money.
- RSVP opens WhatsApp with a pre-filled message. It does not save responses to a database.
- The countdown is set for 12 December 2026 at 10:00 AM India time. Change the time in the `weddingDate` JavaScript line if your ceremony starts at a different time.
- Replace all sample venue/event details and the WhatsApp number before publishing.
